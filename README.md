## 🧘 About

**ZenGarden** is a relaxing browser-based game that lets you cultivate calm through gentle interactions, minimalist visuals, and peaceful sounds.  
Whether you’re taking a short break or seeking a moment of mindfulness, ZenGarden offers a serene digital space to unwind.

---

## 🎮 Features

- 🌸 **Soothing Gameplay:** Interact with your garden in a peaceful environment  
- 🪴 **Minimal Design:** Clean, elegant, and distraction-free  
- 🎵 **Ambient Audio:** Gentle background sounds to enhance relaxation  
- ⚙️ **Lightweight:** Runs smoothly in any modern web browser  
- 💡 **Zero Dependencies:** Built with only HTML, CSS, and JavaScript
